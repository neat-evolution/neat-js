# @neat-evolution/rl-core

`@neat-evolution/rl-core` is the new step-based RL substrate for `neat-js`.

Phase 11 starts this package as an empty scaffold copied from
`@neat-evolution/utils` to save workspace boilerplate setup time.

It will become the home for:

- step-based RL contracts
- rollout helpers
- TD helpers
- policy-gradient helpers
- migrated step-agent algorithm implementations

The initial scaffold is intentionally minimal.
